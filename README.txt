# Culture DNA Chatbot

## Run on Windows

Open PowerShell in this folder and run:

```powershell
pip install -r requirements.txt
streamlit run main.py
```

The browser will open the Culture DNA chatbot.

## Example questions

- What is the traditional food of Jammu?
- Tell me about festivals of Kashmir
- What languages are spoken in Punjab?
- Folk dance of Rajasthan
- Heritage of Himachal Pradesh

The chatbot reads the data from `Culture_DNA.xlsx`.
